# WordPress Portfolio

This repository demonstrates my WordPress skills.  
It is intended to showcase custom themes, plugins, pages, and SEO optimization.

---

## GitHub Repository Setup

Branch structure:

- **main** — stable version of the site, ready to showcase.
- **feature/custom-theme** — my work on a custom theme.
- **feature/elementor-pages** — example pages created with Elementor or another page builder.
- **feature/plugins** — additional plugins or custom functionality.
- **feature/seo-optimization** — examples of SEO optimization (meta tags, page speed, content structure).

💡 The purpose of this structure is to show employers that I can work with Git, WordPress, custom themes and plugins, and SEO.
